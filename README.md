# 番茄短故事创作技能 (fanqie-short-story)

## 简介

此技能专为 **番茄小说平台** 的短故事创作设计，帮助作者高效生产符合平台流量逻辑的爆款短故事。

**适用长度**：
- 超短故事：6000-25000 字
- 中短故事：25000-80000 字

## 可用赛道

Skill 覆盖 8 大赛道，每条赛道有独立的创作规律和技巧：

| 赛道 | 适用场景 | 代表作参考 |
|------|---------|-----------|
| **A. 玄幻仙侠** | 东方玄幻/仙侠/西方奇幻，非现实设定 | 重生、穿书、弹幕、凡人流 |
| **B. 悬疑惊悚** | 解谜求生，紧张压抑氛围 | 规则怪谈、无限循环、闭环反转 |
| **C. 脑洞文** | 系统/弹幕/重生/穿书，可跨背景 | 金手指觉醒、认知错位 |
| **D. 世情爽文** | 现实家庭/婚姻/职场，不公→觉醒→反击 | 偏心父母、被欺压妻子、赡养矛盾 |
| **E. 追妻/追夫火葬场** | 再也无法挽回的伤害为核心 | 男配上位、弹幕/心声信息差 |
| **F. 年代女性成长** | 60-90 年代背景，利用时代特殊性 | 重生高考、创业逆袭、家国情怀 |
| **G. 男频爽文** | 普通中年男主，权力/尊严/背叛 | 身份反转、隐藏能力、职场逆袭 |
| **H. 女性成长** | 从悦他到悦己，自我价值实现 | 学霸逆袭、职场打脸、女性互助 |

## 核心功能

### 1. 标题生成与优选排行
自动生成 5-8 个候选标题，采用 6 种爆款公式（数字悬念式、身份反差式、情感冲突式、悬念疑问式、重生逆袭式、规则怪谈式），按四维评分机制打分排序。

### 2. 社会时事驱动创作
采集近期热点社会新闻，提取核心冲突，经脱敏处理后融入故事创作，极大提升代入感和传播性。

### 3. 5 段式结构
严格按以下比例布局：
- 导语（200-500 字独立高能片段）
- 事件展开（约 20%）
- 冲突升级（约 30%）
- 高潮反转（约 40%）
- 结尾（约 10%）

### 4. 章节钩子系统
每章约 1000 字，章末设置三层钩子（主钩子 + 次钩子 + 情绪钩子）。

### 5. 反转设计
- 超短故事：2-3 次反转
- 中短故事：4-6 次反转

### 6. 字数精度检测
正文完成后自动检测字数偏差，确保在目标 ±10% 以内。

### 7. 手机排版优化
段落 80-150 字、对话独立分行、场景切换空行，符合手机端阅读习惯。

### 8. 短故事拆解与重构
使用 RED 原则（Replace + Emulate + Differentiate）对爆款故事进行六维拆解，再创作全新原创故事。

## 使用方法

Skill 支持**两种交互模式**，根据用户的输入自动匹配：

### 模式A：用户给完整要求 → 直接执行

用户明确告知赛道、字数、核心设定，SKill 跳过选择题，直接进入创作流程。

> *"生成一篇追妻火葬场文，1.5w字左右，男主是总裁，女主隐忍人设"*

执行路径：赛道定位 → 标题生成 → 导语创作 → 正文写作 → 字数检测 → 格式优化。

### 模式B：用户思路模糊 → 逐级选择引导

用户只说"来一篇""写个故事""推荐一下"，Skill 通过**逐级选择法**引导用户一步步明确需求：

```
第1轮：选赛道（8选1）
→ A玄幻仙侠 B悬疑惊悚 C脑洞文 D世情爽文 E追妻火葬场 F年代文 G男频爽文 H女性成长

第2轮：选该赛道热门方向（基于第1轮结果动态给出）
→ 例如选了E追妻火葬场，给出：男主重生追妻 / 男配上位 / 弹幕/心声信息差 / 无法补救的伤害

第3轮：选目标字数
→ 8000字左右 / 13000字左右 / 20000字左右 / 25000字左右

第4轮：确认是否需要结合社会热点（可选）
→ 是 / 否

确认完成后进入正式创作流程。
```

> 每轮只问一个问题，用户选择后自动进入下一轮，不跳步、不一次性抛所有问题。

## 输出路径

生成的短故事默认保存到 `D:\shortnovel\` 目录，文件格式：

```
第一行：标题
第二行：【标签】主分类：XXX | 情节：XXX | 情绪：XXX | 背景：XXX
第三行开始：导语
后续：正文（按章节分）
```
