# 番茄短故事导语创作模板（修订版）

## 导语核心概念

**导语（Lead）** 是200-500字的独立于正文的高能片段，放在文章最前面。

**导语不是故事简介**，而是用"冲突前置+留白+钩子"快速抓住读者的黄金200字。

> 关键区别：
> ❌ 导语 ≠ 全文梗概
> ✔️ 导语 = 最冲突、最反常的高能场景 + 悬念钩子

## 导语构成公式

```
开篇噱头（第1行） → 细节描述（第2-3行） → 情绪递进（第3-4行） → 转折收尾钩子（最后1行）
```

## 3种导语类型模板

### 模板1：悬念式导语（近期爆款首选）

**特点**：重点描写冲突起因或结果，留白部分剧情

**结构**：
```
第1行：反常事件/冲突结果
第2行：具体细节+视觉冲击
第3行：情绪爆发
第4行：悬念钩子（隐藏关键信息）
```

**正确示例**：
```
签购房合同前十分钟，我收到一条陌生短信。
"你用命换来的五十万，他转给了我。"
我抬起头，看到我的未婚夫正微笑着和销售握手。
那个号码，是他另一个手机的。
```
- 前3行：冲突+细节+情绪
- 最后1行：钩子（"另一个手机"暗示双重身份）

### 模板2：梗概式导语

**特点**：概括人物关系和高能剧情，冲突前置，爽点清晰

**结构**：
```
第1行：人物关系 + 极端设定
第2行：当前场景
第3行：冲突升级
第4行：留下疑问
```

**正确示例**：
```
我是全京城最不受宠的王妃。
我的夫君，那个冷面阎王，正在给他心爱的女人剥葡萄。
而那个女人，是我的亲妹妹。
他剥完葡萄，抬头对我说了一句话——
"你，给她跪下。"
```
- 连续3个信息冲击，层层递进
- 最后以对白收尾，制造强烈冲突

### 模板3：引入式导语

**特点**：用对白或动作直接开篇，代入感极强

**结构**：
```
第1行：对白/动作开篇
第2行：人物内心反应
第3行：背景快速交代
第4行：冲突升级/悬念
```

**正确示例**：
```
"跪下。"
新婚第三天，我的丈夫对我说了这两个字。
我以为他在开玩笑。直到我看到他身后的女人——
他出国三年的前女友，回来了。
```
- 第1个字就是冲突
- 信息逐层释放，到最后一句揭晓

## 导语4任务详解

导语必须在**3行内**完成以下4个任务：

### 1. 情绪（必须完成）
牵动读者情绪：愤怒/震惊/同情/好奇/爽快

**技巧**：
- 设计剧情冲突 + 使用情绪化语言 + 营造反差感

### 2. 钩子（必须完成）
制造强烈悬念，让读者产生"为什么"或"后来呢"

**技巧**：
- 日常场景 + 颠覆性发现 + 信息差 + 时间紧迫感

### 3. 共鸣（尽量完成）
建立强代入感，让读者觉得"跟我有关"

**技巧**：
- 讨论社会议题 + 切中大众心理 + 添加身份标签（打工人/全职妈妈/北漂等）

### 4. 创新（酌情完成）
打破审美疲劳，提供差异化内容

**技巧**：
- 概念新 + 视角新 + 结构新（反套路设定）

## 导语创作技巧

### 1. 具象化替代模糊化

```
❌ 描述模糊："我发现丈夫有问题。"
✔️ 具象化冲击："我在丈夫的旧手机里，找到了他给另一个女人的转账记录，备注是：'给宝宝买奶粉'。"
```

### 2. 学会留白

```
❌ 过程冗长：大段叙述发现过程的背景
✔️ 留白艺术："签购房合同前十分钟，我收到一条陌生短信。'你用命换来的五十万，他转给了我。'"
```

### 3. 冲突前置

```
❌ 冲突平淡："今天老公又晚回家了。"
✔️ 冲突前置："结婚三周年纪念日，我收到了一段视频。视频里，我的丈夫正温柔地给另一个女人洗脚。而那个女人，是我用轮椅推了十年的亲妹妹。"
```

### 4. 只说结果，隐藏原因

导语只说冲突的结果和表现，**不要解释过程和原因**。
原因留给正文去展开。

## 导语创作步骤

### 第1步：找出故事最高能的场景
```
问自己：这个故事最让人震惊/愤怒的3个场景是什么？
选取最具视觉冲击力的那个。
```

### 第2步：压缩到3行
```
第1行：冲突结果或反常事件
第2行：具体细节 + 视觉画面
第3行：悬念/钩子
```

### 第3步：测试导语效果
```
1. 朋友看了会追问"然后呢"吗？→ 是/否
2. 删掉前3个字会更紧凑吗？→ 是/否
3. 有明确的人物情绪输出吗？→ 是/否
4. 让人产生了疑问/好奇/期待吗？→ 是/否
→ 全部为"是"才能通过
```

## 导语修改前/后对比

### 案例1
```
❌ 修改前：
我结婚三年了，老公对我越来越冷淡。最近我发现他经常晚回家，我觉得他可能出轨了。我很伤心，不知道该怎么办。

✔️ 修改后：
结婚三周年纪念日，我在丈夫西装口袋里发现了一张妇产科挂号单。
患者姓名：林薇。孕周：12周。
而我的名字，叫陈雯。
```

### 案例2
```
❌ 修改前：
今天是我被公司裁员的第30天。我投了很多简历都没有回音，卡里只剩下3000块钱。房东催我交房租，我不知道该怎么办。

✔️ 修改后：
被裁员的第30天，我的银行卡余额：328.76元。
房东让我三天内搬走。
而此刻，我怀孕了。
```

### 案例3
```
❌ 修改前：
我穿越到了一本小说里，成了恶毒女配。原书里我下场很惨，被男主害死了。我决定改变命运。

✔️ 修改后：
穿成恶毒女配的第一天，男主把我按在墙上。
"再敢动她一根手指，"他压低声音，"我就让你生不如死。"
我笑了。
"巧了，这句话，我也正想对你说。"
```

## 导语常见错误

| 错误 | 问题 | 修改方向 |
|------|------|---------|
| 过程过长 | 前100字都在交代背景 | 删除前50字，从冲突点开始 |
| 描述模糊 | "他对我不好" | 换成具体场景和对话 |
| 情绪平淡 | 陈述事实不带情绪 | 加入感官描写（视觉/听觉/触觉） |
| 缺少钩子 | 交代完了就结束了 | 最后一句必须留悬念 |
| 信息过载 | 把整个故事塞进导语 | 只说最冲突的片段，其余隐藏 |

## 章节钩子设计

正文每章（约1000字）结尾必须设置钩子：

### 常见的钩子类型

**1. 信息揭露型**
```
"就在这时，我的手机亮了一下。
我低头一看，整个人僵住了。
屏幕上是一张照片——三年前车祸现场的照片。
而照片里那个浑身是血的人，就是我现在的丈夫。"
```

**2. 时间紧迫型**
```
"医生说，最多还有三天。
三天，够不够我把真相告诉你？
我不知道。
我只知道，我已经没有下一个三天了。"
```

**3. 人物出场型**
```
"门开了。
进来的不是护士。
是一个我做梦都想不到会出现在这里的人。"
```

**4. 反转预告型**
```
"我以为这就是全部的真相。
直到一周后，我才发现自己错得有多离谱。"
```

---

**使用建议**：
1. 先写导语，再写正文
2. 导语完成后用4任务清单检验
3. 正文每章结尾确保有钩子
4. 全文写完后回头看导语，看是否需要调整
